# Week 4 - Data Cleaning and Visualization Using Power BI

## Project Overview

This project demonstrates the complete process of transforming raw data into meaningful business insights using Microsoft Power BI.

The project involved importing a raw dataset into Power BI, cleaning and transforming the data using Power Query, building calculated measures using DAX, and designing an interactive dashboard to communicate key insights effectively.

The objective was to convert raw, unstructured data into an informative and visually appealing dashboard that supports data-driven decision-making.

# Project Objectives

The objectives of this project were to:

- Import raw datasets into Power BI.
- Clean and transform data using Power Query.
- Improve overall data quality.
- Create calculated measures using DAX.
- Develop an interactive dashboard.
- Present meaningful business insights through visualizations.

# Dataset Preparation

Before creating visualizations, the dataset was cleaned and transformed using Power Query.

The data preparation process included:

- Handling missing (null) values
- Removing duplicate records
- Standardizing data formats
- Renaming columns where necessary
- Verifying data types
- Preparing the dataset for analysis

This ensured that the final dashboard was built using reliable and consistent data.

# Dashboard Features

The dashboard provides an interactive overview of the dataset through various visualizations.

Key dashboard components include:

- KPI Cards
- Charts
- Tables
- Slicers and Filters
- Comparative Analysis
- Interactive Visual Reports
- Key Observations
- Business Recommendations
  
Users can gain deeper insights using the dashboard.

# Analysis Performed

The dashboard was designed to answer important business questions by:

- Identifying trends within the dataset
- Comparing performance across different categories
- Highlighting key performance indicators (KPIs)
- Detecting high and low-performing segments
- Supporting data-driven decision-making
