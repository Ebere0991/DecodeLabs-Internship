# Week 2 - Exploratory Data Analysis (EDA) usine Microsoft Excel

## Project Overview
This project focuses on performing Exploratory Data Analysis (EDA) on a raw dataset using Microsoft Excel. The aim was to transform messy data into a clean, structured dataset, identify data quality issues, generate descriptive statistics, detect outliers, and summarize key insights using pivot tables.

Exploratory Data Analysis is an essential step in every data analysis project as it helps analysts understand the structure, quality, and characteristics of a dataset before performing further analysis or visualization.

## Objectives

The objectives of this project were to:

- Understand the structure and quality of the dataset.
- Clean and prepare the data for analysis.
- Identify and remove inconsistencies.
- Detect potential outliers.
- Generate descriptive statistics.
- Summarize the data using Pivot Tables.
- Produce meaningful insights from the dataset.

## Workbook Structure

This Excel workbook contains five worksheets:

### 1. Messy Data

This sheet contains the original dataset exactly as received before any modifications.

Characteristics include:
- Missing values
- Inconsistent formatting
- Data entry errors
- Irregular spacing

This sheet serves as the raw source of the project.

### 2. Cleaned Data

This worksheet contains the cleaned version of the dataset after performing several data cleaning operations.

Cleaning activities included:

- Handling missing values
- Correcting inconsistent text formatting
- Standardizing data entries
- Correcting data types where necessary
- Improving overall data consistency

This dataset is suitable for further analysis and reporting.

### 3. Outliers

This worksheet identifies unusual or extreme values within the dataset.

The analysis helps to:

- Detect abnormal observations
- Identify possible data entry errors
- Highlight exceptional cases
- Improve data quality
- Support informed decision-making

Outlier detection is an important step in Exploratory Data Analysis because extreme values can significantly influence statistical results.

### 4. Descriptive Statistics

This worksheet summarizes the numerical characteristics of the cleaned dataset.

Statistical measures calculated include:

- Count
- Sum
- Mean (Average)
- Median
- Mode
- Minimum
- Maximum
- Range
- Standard Deviation
- Variance
- Standard Error
- Skewness
- Kurtosis

These measures provide a better understanding of the distribution, spread, and central tendency of the data.

### 5. Pivot Table Analysis

This worksheet contains Pivot Tables created from the cleaned dataset.

The Pivot Tables were used to:

- Summarize large amounts of data
- Compare categories
- Identify trends
- Analyze relationships between variables
- Generate business insights

Pivot Tables make data easier to interpret by presenting summaries in a structured format.
