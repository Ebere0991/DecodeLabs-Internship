# Week 3 - SQL Data Querying and Analysis

## Project Overview

This project demonstrates the use of Structured Query Language (SQL) to retrieve, filter, organize, summarize, and analyze business data stored in a relational database.

The objective of this project was to gain practical experience writing SQL queries to extract meaningful insights from transactional data. Various SQL statements were used to answer business questions, calculate key performance metrics, and summarize sales information.

The project was completed using Microsoft SQL Server Management Studio (SSMS).

# Project Objectives

The objectives of this project were to:

- Understand relational databases.
- Query data using SQL.
- Filter records based on specific conditions.
- Sort datasets.
- Perform calculations using aggregate functions.
- Group records to generate business summaries.
- Answer business questions using SQL queries.
- Develop practical SQL skills for data analysis.

# Dataset

The dataset contains transaction records from a retail business.

Some of the fields used during the analysis include:

- Order ID
- Customer ID
- Product
- Total Price
- Order Status
- Payment Method
- Referral Source
- Shipping Address
- Order Date

These columns were used to perform different SQL operations and generate analytical insights.

# SQL Concepts Covered

Throughout this project, the following SQL concepts were applied:

## SELECT Statement

Used to retrieve specific columns or all records from the database.

Examples include:

- Retrieving all records
- Selecting Product and Total Price
- Selecting Customer ID and Order Status

## WHERE Clause

Used to filter records based on specified conditions.

Examples include:

- Orders with Total Price greater than 1000
- Orders paid using Cash
- Orders where Product equals "Chair"
- Filtering using multiple conditions with AND
  
## ORDER BY

Used to sort query results.

Sorting was performed:

- Ascending Order (ASC)
- Descending Order (DESC)

Examples include:

- Products sorted by Total Price
  
## Aggregate Functions

Several aggregate functions were used to summarize data.

These include:

- SUM()
- COUNT()
- AVG()
- MAX()
- MIN()

The calculations performed include:

- Total Revenue
- Average Sales
- Total Number of Orders
- Highest Sale
- Lowest Sale

## GROUP BY

Used to summarize data by categories.

Analysis was performed for:

- Product
- Order Status
- Shipping Address
- Referral Source
- Payment Method

This allowed meaningful business summaries to be generated.

## TOP Clause

Used to retrieve only the highest-ranking records.

Examples include:

- Top 5 Products by Revenue
- Top 10 Highest Sales Transactions
